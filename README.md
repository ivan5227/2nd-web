# Покедекс

Домашнее задание №3 (переписано с ДЗ №2 на React + TypeScript).

Можно найти покемона по имени или номеру, открыть случайного или сбросить результаты.

## Команда

- Володичев Егор
- Старченко Вячеслав
- Данилин Егор
- Григорьичев Иван

## Что внутри

- React + TypeScript (`strict: true`)
- Vite + CSS Modules
- Zod для проверки ответов от [PokéAPI](https://pokeapi.co/)

## Запуск

```bash
npm install
npm run dev
```

Проверка типов и сборка:

```bash
npm run typecheck
npm run build
npm run preview
```

## Что можно улучшить при ревью

- Вынести загрузку данных из `App` в отдельный хук и добавить отмену запроса через `AbortController`.
- Добавить избранное, фильтр по типам или модальное окно с характеристиками покемона.
- Добавить переключение темы через `Context`.
